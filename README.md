# Описание RU

**Forgotten-Notes-of-MTF** — фанатский некоммерческий архив по игре *SCP: Containment Breach*. Здесь собраны советы по выживанию, разборы механик, сведения об аномалиях, секреты комплекса и интересные факты, которые легко пропустить во время побега.

Проект создан для игроков, которые хотят лучше понять устройство Site-CB, не повторять чужих ошибок и узнать больше о событиях, скрывающихся за закрытыми дверями Фонда.

**Это неофициальный сайт. Он не связан с SCP Foundation, Undertow Games, Third Subvision Studio или иными правообладателями.**

## Возможности сайта

- Советы по выживанию для новичков.
- Карточки с информацией об SCP-объектах из игры.
- Разборы игровых механик: моргание, выносливость, инвентарь, документы.
- Секреты, пасхалки и редкие события.
- Интерактивный квиз.
- Случайный совет или факт.

# Description (EN)

**Forgotten-Notes-of-MTF** is a non-commercial, fan-made archive for the game *SCP: Containment Breach*. It contains survival tips, breakdowns of game mechanics, information on anomalies, facility secrets, and interesting facts that are easy to miss while trying to escape.

This project is designed for players who want to better understand how Site-CB functions, avoid repeating the mistakes of others, and learn more about the events unfolding behind the closed doors of the Foundation.

**This is an unofficial website. It is not affiliated with the SCP Foundation, Undertow Games, Third Subvision Studio, or any other rights holders.**

## Site Features

- Survival tips for beginners.
- Information cards on SCP objects featured in the game.
- Breakdowns of game mechanics: blinking, stamina, inventory, and documents.
- Secrets, Easter eggs, and rare events.
- An interactive quiz.
- A random tip or fact.
